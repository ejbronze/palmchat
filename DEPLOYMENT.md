# Deployment

PalmChat is already hosted on Vercel at `palmchat.io`. This redesign retains the existing project link, root static output, `vercel.json`, CNAME, and deployment settings.

Generate pages with `node scripts/build-pages.mjs` and preview with `node scripts/preview.mjs`. Follow README.md for routes and verification.

Do not commit, push, deploy, change DNS, change production environment variables, or alter the domain configuration before Edwin approves the finished work. After approval, use the existing project workflow and verify an approved preview before release. No migration, project import, or domain setup is needed.
