Professional Learning · Curriculum Design

Edmentum Exact Path Professional Learning

Connecting adaptive-learning data to implementation practice and student support.

PalmChat role

Professional learning designer and facilitator.

Context

Educators and leaders were working with adaptive learning information in the context of broader instructional priorities.

01

Challenge

Digital tools can be underused when teams lack time, context, and a shared implementation approach for translating data into instructional decisions.

02

Approach

Grounded learning in data interpretation, instructional use, planning, and the routines educators need to connect platform information to classroom decisions.

03

Deliverables

  • Facilitated learning sessions
  • Implementation guidance
  • Educator materials
  • Leadership planning support
04

Tools + methods

  • Data-informed instruction
  • Adaptive-learning support
  • Learning design
  • Facilitation
05

Result / intended impact

Focused on helping teams use adaptive-learning tools more strategically and consistently in support of student growth.
